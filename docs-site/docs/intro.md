# 🚀 Getting Started with Prestyler



## Create Prestyler Config File

To begin, create a configuration file for Prestyler:

1. In the root of your project, create a folder named prestyler.

2. Inside it, create a file called prestyler.config.js.

This file defines global settings for the package. The most important setting is prefix, which determines how Bootstrap and custom CSS class names will be prefixed.

Example: prestyler/prestyler.config.js
```js
export default {
  prefix: "ps-"
};
```
If you do not set a custom prefix, Prestyler will use "bs-" as the default.


## Build Prefixed Bootstrap CSS

To generate a CSS file with Bootstrap and Prestyler class names prefixed according to your config, use the following command:

```bash
npx prestyler-build-bs --prefix=<prefix> --input=<input-scss-path> --outDir=<output-directory>
```

Notes:
- All arguments are optional.

- If prestyler.config.js does not exist, this command will create the folder and config file for you automatically.

- The default behavior will use Bootstrap’s core SCSS and output to a default directory (prestyler).

| Argument     | Default                            | Description                                                                 |
|--------------|------------------------------------|-----------------------------------------------------------------------------|
| `--prefix`   | `bs-`                              | Prefix to apply to all class names. Useful to namespace your styles and avoid collisions. |
| `--input`    | `src/styles/bootstrap/bootstrap.scss` | Path to the SCSS entry file that will be compiled to CSS.                  |
| `--outDir`   | `prestyler/` (in current directory) | Directory where the prefixed CSS will be written as `bootstrap-prefixed.css`. |


## Using Prestyler React Components

To ensure Prestyler React components use the correct class prefix (e.g. `bs-`), you need to alias the `prestyler-config` module to point to the config file generated by the CLI.

This allows Prestyler components to import the configuration from your project directly.

### Vite Setup

Add the following to your `vite.config.js`:

```js
import { defineConfig } from 'vite';
import path from 'path';

export default defineConfig({
  resolve: {
    alias: {
      'prestyler-config': path.resolve(__dirname, 'prestyler/prestyler.config.js'),
    },
  },
});
```

### Webpack Setup

Add the following to your `webpack.config.js`:

```js
const path = require('path');

module.exports = {
  resolve: {
    alias: {
      'prestyler-config': path.resolve(__dirname, 'prestyler/prestyler.config.js'),
    },
  },
};
```

That’s it! You’re now ready to start using Prestyler in your project. Next, you can explore how to import components, helpers, and style utilities to speed up your UI development.
